ComQuiz 1.1 - เกมตอบคำถามคอมพิวเตอร์

เพิ่มระดับง่าย / กลาง / ยาก คำถามรวม 90 ข้อ
วิธีเล่น: เริ่มเล่น → เลือกหมวด → เลือกระดับ → ตอบ 10 ข้อ
คะแนนสูงสุดแยกหมวดและระดับ

ลองเล่นบนคอม Windows:
1. แตก ZIP ทั้งหมดก่อน
2. เข้าโฟลเดอร์ ComQuiz
3. ดับเบิลคลิก OPEN_DEMO.bat (ใช้ Python 3 ที่ติดตั้งในเครื่อง)
4. เก็บหน้าต่างคำสั่งไว้ระหว่างเล่น เบราว์เซอร์เปิด http://127.0.0.1:8765

ลองบน Android:
ติดตั้งไฟล์ release/ComQuiz.apk
หากเคยติดตั้ง APK 1.0.0 ที่ส่งก่อนหน้า ต้องถอนตัวเก่าก่อนเพราะใบรับรองทดสอบต่างกัน
การถอนจะลบคะแนนและข้อมูลผู้จัดทำเดิมในแอป อ่าน README.md ก่อนติดตั้งแทน

แก้ไขซอร์สใน VS Code:
เปิดโฟลเดอร์ ComQuiz ที่มี pubspec.yaml แล้วใช้ run_windows.bat
ต้องติดตั้ง Flutter และ Chrome ก่อน

ชื่อเริ่มต้นคือ Kan รหัสนักศึกษายังว่าง
แก้ข้อมูลชั่วคราวในหน้า ผู้จัดทำ ของแอปได้
หากจะทำฉบับส่ง: แก้ author.json และสร้าง APK ใหม่ด้วย build_apk.bat

อ่าน README.md และ docs/PROJECT_GUIDE.md สำหรับวิธีใช้งานและรายการส่งงาน
อ่าน docs/VALIDATION.md สำหรับผลตรวจและข้อจำกัดที่ตรวจได้จริง
