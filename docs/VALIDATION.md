# ผลตรวจ ComQuiz 1.1.0

วันที่ตรวจ: 27 ตุลาคม 2569

## ซอร์สและชุดทดสอบ

- Flutter 3.35.7 / Dart 3.9.2
- `flutter analyze --no-pub`: ไม่พบปัญหา
- `flutter test --no-pub --reporter expanded`: ผ่านทั้งหมด 20 เคส
- คำถาม 90 ข้อ ไม่ซ้ำทั้งรหัสและข้อความ แยกครบ 3 หมวด × 3 ระดับ × 10 ข้อ
- คำถามมี 4 ตัวเลือกไม่ซ้ำและมีเฉลย; คำถามเดิม 30 ข้ออยู่ในระดับง่าย
- ทดสอบทุกชุดด้วยลำดับสุ่ม 5 แบบ: คำตอบยังตรง ระดับไม่ปะปน และผลคะแนนอ่านกลับได้
- ปฏิเสธการข้ามข้อ ตอบซ้ำ คำตอบผิดช่วง และจบรอบก่อนครบ
- คิดคะแนน 0, 50, 100 ถูกต้อง; คะแนนสูงสุดแยกตามหมวดและระดับ
- จำกัดประวัติ 30 รอบโดยยอดรวมไม่ถูกตัด; แสดงประวัติล่าสุด 10 รอบ
- บันทึก โหลดใหม่ ล้างสถิติ การเขียนล้มเหลว การลองบันทึกซ้ำ และข้อมูลเสียหาย
- ย้ายข้อมูลเก่าเป็นระดับง่าย แล้วเพิ่มรอบยากและโหลดกลับได้โดยยอดเดิมไม่หาย
- ทดสอบเส้นทางครบ 7 หน้า การแก้ไขผู้จัดทำ เล่นซ้ำระดับเดิม และกลับหน้าระดับแล้วคะแนนอัปเดต
- เลือกครบทั้ง 3 ระดับ และออกจากรอบที่ยังไม่จบโดยไม่บันทึก
- จอ 320×740 รวมสถิติครบ 9 ชุด: ไม่พบ layout overflow ในเส้นทางที่ทดสอบ

## เว็บเดโม

- Release build สำเร็จ รวมฟอนต์และ CanvasKit ในแพ็กเกจ
- Chrome Headless 156.0.8078.47; บล็อกการเรียกทรัพยากรภายนอกทั้งหมด
- เล่นเว็บรุ่น 1.0.0 หมวดฮาร์ดแวร์จบ 10 ข้อ ได้ 100 คะแนน
- เปลี่ยนเป็นเว็บรุ่น 1.1.0 บน origin เดิม: คะแนนเดิมเป็นฮาร์ดแวร์–ง่าย 100
- เล่นรุ่นใหม่อีก 3 รอบ: ฮาร์ดแวร์–กลาง 80, ซอฟต์แวร์–ยาก 60, อินเทอร์เน็ต–ง่าย 100
- รีโหลดแล้วมี 4 รอบ ตอบถูก 34/40 ข้อ (85%) และคะแนนสูงสุดทั้ง 4 ชุดยังแยกกัน
- ตรวจภาพหน้าเลือกระดับที่ 390×844 และ 320×740 รวมภาพผลคะแนนและสถิติ
- ไม่พบ JavaScript page error ในเส้นทางที่ทดสอบ

## Android

- ใช้ JDK 17 แบบเต็ม; `flutter build apk --release --no-pub --dart-define-from-file=author.json`: สำเร็จ
- Package th.ac.student.comquiz, version 1.1.0 (2)
- Android 7.0 / API 24 ขึ้นไป; target SDK 36
- รวม ABI armeabi-v7a, arm64-v8a, x86_64
- apksigner verify ผ่าน; ลายเซ็น APK v2 ถูกต้อง
- aapt dump badging: ชื่อ ComQuiz และไม่มีสิทธิ์ INTERNET
- APK archive CRC ผ่าน; SHA-256 อยู่ใน release/SHA256.txt
- ใบรับรองทดสอบต่างจาก APK 1.0.0 ที่เคยส่ง ต้องถอนตัวเก่าก่อนติดตั้งถ้ามีตัวเก่าอยู่
- การถอนแอปลบข้อมูลในเครื่อง; การย้ายสถิติที่ทดสอบสำเร็จไม่ใช่การรับประกันว่าข้อมูลจะอยู่หลังถอนแอป

## ข้อจำกัด

- ยังไม่ได้ติดตั้งและเล่นบนโทรศัพท์ Android จริง
- ยังไม่ได้รัน GitHub Actions บนบัญชีผู้ใช้ หรือสคริปต์ Windows บน Windows จริง
- ชื่อเริ่มต้น Kan; รหัสนักศึกษายังว่าง แก้ author.json และ build ใหม่หากต้องการเปลี่ยนค่าเริ่มต้น
- การอัปเดตนี้ไม่รวม repository รายงาน DOCX/PDF วิดีโอ หรือภาพส่งงานใหม่
- คะแนนเก็บเฉพาะเครื่อง ไม่ซิงก์ข้าม Android และเบราว์เซอร์
