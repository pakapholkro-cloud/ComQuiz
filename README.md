# ComQuiz

ComQuiz เป็นเกมตอบคำถามความรู้คอมพิวเตอร์ที่พัฒนาด้วย Flutter และ Dart สำหรับโครงงานวิชาการพัฒนาโปรแกรมประยุกต์สำหรับอุปกรณ์เคลื่อนที่ ผู้เล่นเลือกหมวดและระดับความยากที่ต้องการทบทวนได้

## ความสามารถของแอป

- คำถาม 90 ข้อ แบ่งเป็นฮาร์ดแวร์ ซอฟต์แวร์ และอินเทอร์เน็ต
- แต่ละหมวดมีระดับง่าย กลาง และยาก
- เล่นรอบละ 10 ข้อ ข้อละ 4 ตัวเลือก ตอบถูกได้ 10 คะแนน คะแนนเต็ม 100
- แสดงเฉลยและคำอธิบายหลังตอบแต่ละข้อ โดยไม่จับเวลา
- ดูผลคะแนนและสถิติย้อนหลังได้ คะแนนเก็บไว้ในอุปกรณ์ที่ใช้เล่น

## เครื่องมือที่ใช้

Flutter, Dart และ shared_preferences สำหรับบันทึกคะแนนกับสถิติภายในเครื่อง

## วิธีเปิดแอปผ่าน Codespaces

1. เปิด Repository และเลือก Code → Codespaces → Create codespace on main
2. ตรวจสอบว่าติดตั้ง Flutter แล้วด้วยคำสั่ง `flutter --version` หากพบ `command not found` ต้องติดตั้ง Flutter SDK ก่อน
3. เปิด Terminal ในโฟลเดอร์ ComQuiz และรัน

```bash
bash run_codespaces.sh
```

4. เมื่อแอปเริ่มทำงาน เปิดแท็บ PORTS แล้วเปิดพอร์ต 8080 ในเบราว์เซอร์

## วิธีรันบนคอมพิวเตอร์

ติดตั้ง Flutter และ Chrome ก่อน แล้วใช้คำสั่งในโฟลเดอร์โปรเจกต์

```bash
flutter pub get
flutter run -d chrome --dart-define-from-file=author.json
```

## สร้างไฟล์ APK

เลือก Actions → Build ComQuiz APK → Run workflow บน GitHub กรอกชื่อและรหัสนักศึกษา เมื่อ Build สำเร็จจึงดาวน์โหลดไฟล์ APK จาก Artifacts ได้ หรือใช้คำสั่ง `flutter build apk --release --dart-define-from-file=author.json` บนเครื่องที่เตรียม Flutter และ Android SDK ไว้แล้ว

Repository นี้เก็บซอร์สโค้ด **ไม่ได้แนบ APK หรือเว็บเดโมที่คอมไพล์แล้ว** จึงต้องสร้างไฟล์ติดตั้งจากโค้ดก่อนใช้งาน และควรทดสอบบนมือถือจริงก่อนส่งงาน

## โครงสร้างไฟล์หลัก

| ไฟล์หรือโฟลเดอร์ | หน้าที่ |
| --- | --- |
| `lib/main.dart` | เริ่มต้นแอป |
| `lib/screens/screens.dart` | หน้าจอเกม |
| `lib/data/` | คำถามและระดับความยาก |
| `lib/models/quiz.dart` | กติกาและการคำนวณคะแนน |
| `lib/services/app_store.dart` | จัดเก็บสถิติ |
| `test/` | ทดสอบการทำงาน |
| `android/`, `web/` | ไฟล์สำหรับแต่ละแพลตฟอร์ม |
