# ComQuiz

เกมตอบคำถามคอมพิวเตอร์ภาษาไทย 7 หน้าจอ พัฒนาด้วย Flutter
โทนกรมท่า–ฟ้า มีคำถาม 90 ข้อ แบ่งเป็นฮาร์ดแวร์ ซอฟต์แวร์ และอินเทอร์เน็ต

## ลองเล่นแบบเร็วบน Windows

1. แตก ZIP ทั้งหมด แล้วเข้าโฟลเดอร์ `ComQuiz`
2. เปิด `OPEN_DEMO.bat` (เครื่องต้องมี Python 3)
3. เบราว์เซอร์จะเปิด `http://127.0.0.1:8765`
4. เปิดหน้าต่างคำสั่งค้างไว้ขณะเล่น เมื่อจบกด Ctrl+C หรือปิดหน้าต่าง

เดโมใน `preview/` คอมไพล์จาก Flutter ชุดเดียวกับแอป Android
อย่าดับเบิลคลิก `preview/index.html` โดยตรง เพราะ Flutter Web ต้องเปิดผ่านเว็บเซิร์ฟเวอร์
หากเบราว์เซอร์ไม่เปิดเอง ให้พิมพ์ URL ด้านบน ใช้ Chrome หรือ Edge ที่รองรับ WebGL
ข้อมูลสถิติของเดโมจะเก็บเฉพาะเบราว์เซอร์และที่อยู่เว็บนั้น ไม่ได้ซิงก์กับ Android

macOS/Linux ที่มี Python 3 ใช้ `python3 tools/preview_server.py`

## ลองเล่นบน Android

ไฟล์ `release/ComQuiz.apk` เป็น APK สำหรับติดตั้งทดลองบน Android 7.0 ขึ้นไป
คัดลอกไฟล์ไปโทรศัพท์ เปิดไฟล์ แล้วอนุญาตการติดตั้งจากแอปที่ใช้เปิดไฟล์ตามที่ Android ถาม
ตัวแอปไม่ต้องมีบัญชี ไม่ต้องเปิดอินเทอร์เน็ต และไม่มีระบบซื้อสินค้า
ให้ลองบนโทรศัพท์จริงของตนเองก่อนใช้ถ่ายคลิปหรือส่งงาน


### ติดตั้งแทน APK รุ่นเก่าที่ได้รับก่อนหน้านี้

APK 1.1.0 นี้ใช้ใบรับรองทดสอบคนละใบกับ APK 1.0.0 ที่เคยส่ง จึงติดตั้งทับตัวเก่าไม่ได้
ถ้ามีตัวเก่าอยู่ ให้จดหรือถ่ายภาพคะแนนที่ต้องการเก็บ แล้วถอน ComQuiz ตัวเก่าก่อนติดตั้งไฟล์ใหม่
การถอนแอปจะลบสถิติและข้อมูลผู้จัดทำที่บันทึกในแอป ไม่สามารถนำภาพคะแนนกลับเข้าระบบอัตโนมัติได้
หากยังไม่เคยติดตั้ง สามารถติดตั้งไฟล์ใหม่ได้โดยตรง
เว็บเดโมที่ใช้เบราว์เซอร์และที่อยู่เดิมย้ายสถิติเก่าเป็นระดับง่ายได้ตามที่ทดสอบ

## กติกา

- เลือกหนึ่งหมวด แล้วเลือกระดับง่าย กลาง หรือยาก เล่นรอบละ 10 ข้อ
- คำถามแยกชุดตามหมวดและระดับ สุ่มลำดับคำถามและตัวเลือก
- ตอบได้หนึ่งครั้งต่อข้อ ตอบถูกได้ 10 คะแนน ตอบผิดได้ 0 คะแนน
- แสดงคำอธิบายทันที ไม่จับเวลา
- เล่นจบจึงบันทึกคะแนน ออกก่อนครบจะไม่บันทึก
- เก็บคะแนนสูงสุดแยกครบ 9 ชุด (3 หมวด × 3 ระดับ) พร้อมจำนวนรอบ อัตราตอบถูก และประวัติในเครื่อง
- เล่นซ้ำระดับเดิมหรือเปลี่ยนระดับได้จากหน้าผลคะแนน
- เมื่อมีข้อมูลจากเวอร์ชันเดิม สถิติเดิมจะนับเป็นระดับง่าย โดยยอดรวมยังคงอยู่
- เปิดหน้าสถิติเพื่อล้างข้อมูลได้ มีการถามยืนยันก่อนล้าง

## แก้โค้ดและรันใน VS Code

ใช้ Flutter 3.35.7 / Dart 3.9.2 ที่ใช้ตรวจโปรเจกต์นี้
ติดตั้ง Flutter extension ใน VS Code และตรวจ `flutter doctor`
เปิดโฟลเดอร์นี้ที่มี `pubspec.yaml` ไม่ใช่เปิดเฉพาะไฟล์ `main.dart`

```bash
flutter pub get
flutter run -d chrome --dart-define-from-file=author.json
```

บน Windows ใช้ `run_windows.bat` หรือเลือก **ComQuiz - Chrome** แล้วกด F5
บน GitHub Codespaces ใช้ `bash run_codespaces.sh` แล้วเปิดพอร์ต 8080
หน้าตาเดโมปรับตามขนาดหน้าจอ ลองย่อหน้าต่างหรือใช้โหมดจำลองมือถือของเบราว์เซอร์ได้
หากต้องการ Android Emulator ต้องติดตั้ง Android Studio และสร้างอุปกรณ์จำลองแยก

## ใส่ชื่อและรหัสนักศึกษา

ข้อมูลเริ่มต้นอยู่ใน `author.json`:

```json
{"AUTHOR_NAME":"Kan","STUDENT_ID":""}
```

แก้เป็นชื่อจริงและรหัสของตนเอง แล้วรันหรือ build ด้วย `--dart-define-from-file=author.json`
ชื่อที่เปลี่ยนในหน้า **ผู้จัดทำ** เก็บเฉพาะอุปกรณ์นั้น ไม่ได้แก้ไฟล์ APK หรือซอร์สให้เครื่องอื่น
หากอุปกรณ์เคยบันทึกชื่อไว้ ข้อมูลที่บันทึกไว้จะมาก่อนค่าเริ่มต้นใหม่

## สร้าง APK ของตนเอง

ต้องมี Flutter, JDK 17 และ Android SDK ที่ `flutter doctor` ตรวจผ่าน
ติดตั้ง Android SDK Platform 36 และ Build Tools 35.0.0 หากเครื่องยังไม่มี

```bash
flutter pub get
flutter build apk --release --dart-define-from-file=author.json
```

หรือเปิด `build_apk.bat` บน Windows
ไฟล์ออกที่ `build/app/outputs/flutter-apk/app-release.apk`
โปรเจกต์ใช้ debug signing สำหรับทดลองในชั้นเรียน ต้องตั้ง signing ของตนเองหากจะเผยแพร่บนสโตร์

อีกทางหนึ่ง: อัปโหลดซอร์สไป GitHub repository ของตนเอง
ไป **Actions → Build ComQuiz APK → Run workflow** ใส่ชื่อและรหัส แล้วดาวน์โหลด artifact เมื่อสำเร็จ
มีไฟล์ workflow เตรียมไว้ แต่ยังไม่ได้รันบนบัญชี GitHub ของผู้ใช้

## โครงสร้างโค้ด

| ไฟล์/โฟลเดอร์ | หน้าที่ |
| --- | --- |
| `lib/main.dart` | เริ่มแอป โหลดข้อมูล ตั้งธีม |
| `lib/screens/screens.dart` | หน้าจอทั้ง 7 และการนำทาง |
| `lib/ui/design.dart` | ธีม องค์ประกอบร่วม ภาพวงจรที่วาดด้วยโค้ด |
| `lib/models/quiz.dart` | กติกาเกม การสุ่ม คำนวณคะแนน และโมเดลสถิติ |
| `lib/data/question_bank.dart` | รวม 90 ข้อ โดย 30 ข้อเดิมเป็นระดับง่าย |
| `lib/data/difficulty_questions.dart` | ระดับกลางและยากเพิ่ม 60 ข้อ พร้อมเฉลย |
| `lib/services/app_store.dart` | อ่าน–เขียนสถิติและข้อมูลผู้จัดทำ |
| `test/` | ทดสอบกติกา การบันทึก และเส้นทางการเล่น |
| `assets/fonts/` | ฟอนต์ Sarabun และใบอนุญาต OFL |
| `android/`, `web/` | โครงสร้างแพลตฟอร์ม Flutter |
| `docs/PROJECT_GUIDE.md` | อธิบายงาน เทียบโจทย์ และรายการเตรียมส่ง |
| `docs/VALIDATION.md` | ผลทดสอบจริงและข้อจำกัด |

## ตรวจโปรเจกต์

```bash
flutter analyze --no-pub
flutter test --no-pub
```

สถิติรวมจะนับทุกเกมที่จบ ประวัติเก็บสูงสุด 30 รอบและแสดง 10 รอบล่าสุด
shared_preferences เหมาะกับข้อมูลเดโมขนาดเล็ก ไม่ใช่ฐานข้อมูลสำคัญหรือข้อมูลสอบ
ถอนแอป ล้างข้อมูล หรือใช้โหมดส่วนตัวของเบราว์เซอร์อาจทำให้ข้อมูลไม่คงอยู่
